# 更新升级指南

## 脚本更新（推荐）

运行安装脚本，选择 `4` 进行更新：

```bash
curl -fsSL https://6qu.cc/dns2/install.sh | bash
```

```
========================================
    六趣DNS 管理脚本 v3.0
========================================

  1. 使用已有 MySQL 安装
  2. 完整安装（应用 + MySQL）
  3. 轻量安装（SQLite）
  ────────────────────────────────────────
  4. 更新              ← 选择此项
  5. 查看状态
  6. 查看日志
  7. 重启服务
  8. 备份数据
  9. 卸载
  0. 退出

========================================
```

选择 `4` 后，脚本会自动：

1. 检测当前部署模式（已有 MySQL / 完整安装 / SQLite）
2. 拉取最新应用镜像
3. 重启应用容器（数据库不受影响）

配置文件、数据库、插件、主题等数据都不会丢失。

## 更新前备份

建议更新前先备份数据，选择菜单中的 `8. 备份数据`：

```
========================================
  备份数据
========================================

  → 当前模式: 完整安装（应用 + MySQL）
  → 备份数据库...
  → 备份配置文件...
  → 备份插件和主题...

  ✓ 备份完成！
  备份文件: /opt/dns/backups/backup_20260401_120000.tar.gz
========================================
```

备份内容包括：
- 数据库（MySQL 使用 mysqldump，SQLite 复制文件）
- 配置文件（.env、docker-compose.yml）
- 插件目录
- 主题目录

## 手动更新

如果脚本更新失败，可以手动更新：

```bash
cd /opt/dns

# 拉取最新镜像
docker pull 167729539/dns:latest

# 重启应用容器（不影响数据库）
docker compose stop app
docker compose up -d
```

> 如果使用的是旧版 docker-compose，将 `docker compose` 替换为 `docker-compose`。

## 常见更新问题

### 1. 更新失败

- 检查网络连接是否正常
- 检查 Docker 服务是否运行：`systemctl status docker`
- 查看日志了解具体错误：`docker logs dns-app`

### 2. 更新后页面异常

- 清除浏览器缓存
- 或强制刷新：`Ctrl + Shift + R`

### 3. 更新后数据库报错

新版本可能包含数据库结构变更，应用启动时会自动执行迁移。如果迁移失败：

```bash
# 查看详细错误日志
docker logs dns-app --tail 50
```

如有问题请联系技术支持。
